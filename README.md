# ChatGeo 🌍🤖

**ChatGeo** is an interactive application designed to bridge the gap between geographical data and conversational artificial intelligence. By combining natural language processing with spatial tools, ChatGeo allows users to query, analyze, and explore location-based insights through intuitive, chat-driven interactions.

---

### ✨ Key Features
* **Natural Language Queries:** Ask complex geographic questions in plain text.
* **Spatial & Map Integration:** Real-time visual rendering of geographic coordinates, imagery, and datasets.
* **Interactive Data Insights:** Get immediate context, statistics, and analysis for specified locations.
